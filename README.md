A **TABLE** é um sistema web criado para facilitar a vida de jogadores e mestres de RPG. O objetivo do projeto é reunir em uma única plataforma as ferramentas essenciais para criar, organizar e conduzir campanhas de forma totalmente digital e imersiva.

## ✨ O que o projeto faz?

* **🧙‍♂️ Fichas Digitais Interativas:** Criação passo a passo de personagens com abas para Descrição, Origens, Atributos e Classes. O sistema conta com distribuição inteligente de pontos e validação automática.
* **⚙️ Criação de Sistemas Customizados:** Um painel exclusivo para Mestres criarem suas próprias regras, adicionando status, atributos e componentes como Perícias e Monstros.
* **📖 Guia de Jogo:** Uma área dedicada a ensinar iniciantes, separando as responsabilidades de como atuar como "Jogador" e como "Mestre".

## 🚀 Tecnologias Utilizadas

Este projeto foi construído com tecnologias front-end puras para garantir um design único, responsivo e de alta performance:

* **HTML5:** Estrutura e semântica de todas as páginas.
* **CSS3:** Estilização com Dark Theme, Flexbox, Grid e animações personalizadas.
* **Vanilla JavaScript:** Lógica de interações, controle de abas, cálculos matemáticos de atributos e alertas visuais.

## 💻 Como testar o projeto

1. Faça o download ou clone este repositório.
2. Abra a pasta do projeto no seu computador.
3. Dê um duplo clique no arquivo `index.html` para abrir diretamente no seu navegador.
